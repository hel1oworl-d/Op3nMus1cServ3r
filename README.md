# Op3nMus1c / Hel1oMus1c Microservices Backend

Высокопроизводительный модульный бэкенд для стримингового музыкального сервиса Hel1oMus1c.

## Архитектура и микросервисы

- **Core Gateway & Auth API** (`backend/core`, порт `8001`):
  - Авторизация через Telegram-бота по одноразовым криптографическим ссылкам/вызовам (Anti-Hijack).
  - Выдача короткоживущих JWT Access токенов (HS256) и хешированных Refresh токенов с ротацией при каждом обновлении.
  - Принудительная проверка заголовка `X-Client-Version` с возможностью динамической настройки минимально поддерживаемой версии в `music.json`.
- **Telegram Bot** (`bot`):
  - Привязка авторизации устройств к Telegram-аккаунтам.
  - Управление подписками (Lava / автопродление), профилем, плейлистами, загрузка пользовательских MP3 аудио.
  - Админ-панель управления пользователями и бета-тестом.
- **YouTube Music Service** (`backend/yt-music`, порт `8010`):
  - Поиск, парсинг треков и извлечение стримов.
- **SoundCloud Service** (`backend/soundcloud`, порт `8011`):
  - Резолвинг аудио-потоков и HD-обложек SoundCloud.
- **LRCLIB Lyrics Service** (`backend/lrclib`, порт `8012`):
  - Синхронизированные и текстовые тексты песен с кэшированием.

## Конфигурация (`music.json`)

Все глобальные параметры проекта настраиваются в файле `music.json`:
- `domain`: привязанный домен сервера (для автонастройки Nginx и SSL).
- `security.min_client_version`: минимальная версия клиента, допускаемая к авторизации (например, `"1.0.0"`). Любая версия ниже будет отклонена с `426 Upgrade Required`.
- `security.jwt_secret`: ключ подписи токенов.
- `security.app_secret_key`: секретный ключ клиента для проверки в заголовке `X-App-Secret`.

## Быстрая установка и развертывание

Для полного автоматического развертывания проекта выполните:
```bash
./deploy.sh
```

Установщик автоматически:
1. Установит необходимые зависимости из `requirements.txt`.
2. Создаст нужные каталоги для загрузок и медиа.
3. Сгенерирует systemd сервисы: `openmusic-core`, `openmusic-bot`, `openmusic-lrc`, `openmusic-yt`, `openmusic-sc`.
4. Сгенерирует и активирует конфигурацию Nginx для указанного домена с маршрутизацией запросов и rate-limiting.
5. Запустит и включит автозагрузку всех сервисов.
